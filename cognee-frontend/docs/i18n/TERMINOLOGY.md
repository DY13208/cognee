# Cognee UI 中英术语表

本表是 UI 文案的规范来源。翻译的目标是清晰、专业且面向知识管理用户；不是逐词
直译。用户数据、模型输出、代码、日志、字段名、API 载荷和原始技术异常不属于 UI
词典，不得自动翻译。

## 不翻译的专有名词

下列名称在两种语言中保持原样：`Cognee`、`Cognify`、MCP、API、LLM、Embedding、
pgvector、Kuzu、Neo4j、PostgreSQL、JSON、OAuth、OpenAI、Claude、Swagger、Docker、GitHub。

首次向中文用户解释 `Cognify` 时，写作“构建知识（Cognify）”；按钮和简短动作使用
“构建知识”。英文界面始终使用 `Cognify`。

## 产品概念

| 英文原词 / 上下文 | 简体中文 UI | 使用说明 |
| --- | --- | --- |
| Brain（数据资产入口） | 知识库 | 不译为“大脑”；内部 API/模型名称不变。 |
| Dataset | 数据集 | 指知识库中的可管理数据单元。 |
| Search（检索知识） | 检索 | 作为功能和动作；普通页面内查找可用“搜索”。 |
| Knowledge Graph / Mindmap（图关系视图） | 知识图谱 | 不使用“思维导图”，除非功能确为思维导图。 |
| Session | 会话 | 不译为“会议”。 |
| Agent | 智能体 | 作为自主执行任务的软件实体。 |
| Skill | 技能 | 可在帮助文字首次写作“技能（Skill）”。 |
| Integration | 集成 | 外部服务/连接器集成。 |
| Connection | 连接 | 指已配置的服务连接或凭据关联。 |
| Tenant | 租户 | 多租户隔离上下文。 |
| API Key | API 密钥 | 保留 API 缩写。 |
| Revoke（作废 API 密钥） | 撤销 | 使密钥立即失效；不是删除文件。 |
| Workspace | 工作区 | 租户对应的工作区。 |
| Overview | 概览 | 仪表盘首页。 |
| Settings | 设置 | 账号与工作区设置。 |
| Members | 成员 | 工作区成员管理。 |
| Onboarding | 引导 | 首次设置流程。 |
| Analytics | 分析 | 用量与效果统计。 |
| Activity | 动态 | 操作记录；不译为“活动”，以免与会话混淆。 |
| Memory coverage | 记忆覆盖 | 记忆缺口分析页。 |
| Billing | 账单 | 云端订阅与用量；价格页可写作“账单 / 价格”。 |
| Graph model | 图谱模型 | 指图谱的模型/本体配置。 |
| Ontology | 本体 | 知识工程术语，不译为“本体论”。 |
| Prompt（抽取提示词） | 提示词 | 指导实体与关系抽取的指令；不是操作系统的命令提示符。 |
| Schema（图谱实体与关系定义） | 图谱结构 | 仅用于图谱模型推断/编辑；数据库 schema 仍保留英文。 |
| Ingestion | 导入 | 指把数据导入知识库的过程。 |
| Recall | 记忆检索 | 仅用于 Cognee 记忆能力；一般检索仍用“检索”。 |
| Remember（写入记忆） | 写入记忆 | 与记忆检索相对的写入动作；英文界面保持 Remember。 |

未出现在本表中的产品或技术名，默认保留英文；在合并中文文案前先补充本表并由维护者
审核。不得为追求中文化而臆造译名。

## 风格规则

- 操作按钮使用简洁动词，如“保存”“取消”“删除”“构建知识”；避免“进行保存”。
- 危险操作必须说清对象和后果，例如“删除知识库会永久删除其中的数据集及文件”。
- 空状态说明下一步可做什么；校验错误说明可操作的修复方式。
- 中文使用全角中文标点；英文保持原有英文标点。变量、ID、文件名、命令和代码用原值。
- 当句中夹杂未翻译品牌或缩写时，不额外添加中文空格，除非 Markdown/代码格式需要。
