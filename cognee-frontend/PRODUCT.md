# PRODUCT.md

## Register

product

## Product

Cognee Cloud UI — AI memory / knowledge-graph workspace for datasets, search, integrations, and teleology (purpose edges).

## Users

Operators and knowledge engineers who need to answer: what is this entity, who relates to it, upstream/downstream impact — not to admire a full-graph hairball.

## Personality

Restrained, dense, trustworthy. Linear / Figma / Neo4j Bloom class tools. Dark surfaces, quiet accents, high information density.

## Anti-references

Cyberpunk glow, giant purple circle nodes, full-graph spider webs, decorative gradient hero chrome.

## Principles

1. Focus-first: never dump the whole graph; start from a selected entity.
2. Cards over orbs: entity info cards with type stripe, not decorative nodes.
3. Click selects; double-click / “设为中心” changes focus.
4. Expand on demand (+N), filter hops and relation types.
